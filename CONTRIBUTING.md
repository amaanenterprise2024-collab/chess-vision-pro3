# Contributing to Chess Vision Pro

Thank you for considering contributing to Chess Vision Pro! We welcome contributions of all kinds.

## How to Contribute

### Reporting Bugs
1. Check if the bug has already been reported in Issues
2. Create a detailed bug report including:
   - Description of the bug
   - Steps to reproduce
   - Expected behavior
   - Actual behavior
   - Screenshots if applicable

### Feature Requests
1. Describe the desired feature
2. Explain why it would be useful
3. Provide examples or use cases

### Code Contributions

1. **Fork** the repository
2. **Create a branch** for your feature:
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make changes** following the code style:
   - Use Kotlin best practices
   - Follow MVVM architecture pattern
   - Write meaningful commit messages
   - Add comments for complex logic

4. **Commit your changes:**
   ```bash
   git commit -am 'feat: Add your feature description'
   ```

5. **Push to your branch:**
   ```bash
   git push origin feature/your-feature-name
   ```

6. **Create a Pull Request:**
   - Link related issues
   - Describe changes in detail
   - Add screenshots for UI changes
   - Request reviews from maintainers

## Code Style Guidelines

- Use meaningful variable and function names
- Keep functions small and focused
- Add comments for complex logic
- Use Kotlin idioms and best practices
- Follow Google's Kotlin style guide

## Testing

- Write unit tests for new features
- Run existing tests before submitting
- Test on multiple Android versions

## Commit Message Format

Use conventional commits:
- `feat:` - New feature
- `fix:` - Bug fix
- `docs:` - Documentation
- `style:` - Formatting
- `refactor:` - Code refactoring
- `test:` - Adding tests
- `chore:` - Maintenance

## Pull Request Process

1. Update README with any new features
2. Update CHANGELOG.md
3. Ensure all tests pass
4. Get approval from at least 1 maintainer
5. Merge to main branch

## Questions?

Feel free to open an issue or contact the maintainers.

Thank you for contributing!
